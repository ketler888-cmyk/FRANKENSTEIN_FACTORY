# ФАБРИКА ФРАНКЕНШТЕЙНА

Фабрика стратегий ИИ (Франкенштейн): генетический алгоритм + тестирование стратегий + эволюция.

## Что в репозитории
- Код фабрики (ядро)
- Конфиги / инструкции

## Что НЕ в репозитории
- Данные свечей (SCALPING_DATA*)
- Результаты прогонов (results*, results_ga*)
- Логи (logs*)
